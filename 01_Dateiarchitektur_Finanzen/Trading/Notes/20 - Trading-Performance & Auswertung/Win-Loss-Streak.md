# Win-Loss-Streak


## Kurzdefinition

- Ein Run ist eine ununterbrochene Folge von Renditen mit demselben Vorzeichen.

## Kernaussagen

- Investmentstrategien erzeugen selten Renditen aus einem unabhängig und identisch verteilten Prozess.
- Ohne unabhängig und identisch verteilte Renditen treten häufig Runs auf.
- Runs erhöhen das Abwärtsrisiko.
- Die Konzentration positiver Renditen und die Konzentration negativer Renditen werden mit einem Maß erfasst, das vom Herfindahl-Hirschman-Index angeregt ist.
- Das Gewicht einer Rendite ist ihr Wert geteilt durch die Summe der Renditen desselben Vorzeichens.
- Das Konzentrationsmaß liegt zwischen 0 und 1.
- Das Konzentrationsmaß ist 0 genau dann, wenn alle Gewichte gleich sind.
- Das Konzentrationsmaß ist 1 genau dann, wenn nur eine Rendite von null verschieden ist.
- Dieselbe Konstruktion misst, wie stark die Wetten auf einzelne Monate gebündelt sind.

## Voraussetzungen

- Das Maß ist definiert, wenn mehr als eine Rendite des jeweiligen Vorzeichens vorliegt.
- Die Grenzen 0 und 1 folgen daraus, dass das Quadrat des Mittelwerts höchstens dem Mittelwert der Quadrate entspricht und dieses Verhältnis höchstens die Anzahl der Renditen erreicht.

## Regeln und Kriterien

- Erwünscht ist eine niedrige Konzentration der Verluste, also kein dicker linker Rand.
- Erwünscht ist eine niedrige zeitliche Konzentration der Wetten.
